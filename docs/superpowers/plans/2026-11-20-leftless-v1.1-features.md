# Leftless 1.1 Features — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add batch uninstall, an orphaned-leftovers scan, an opt-in Trash watcher and app reset, then ship v1.1.0.

**Architecture:** Core first (history operation + batched Uninstaller), then each feature as core logic with unit tests plus a thin SwiftUI layer. Every new UI string goes into the String Catalogs in all 7 languages (the existing `LocalizationCatalogTests` enforce it).

**Tech Stack:** Swift 6.1, SwiftUI, SwiftPM + XcodeGen project, Swift Testing, ServiceManagement (`SMAppService`), UserNotifications, Dispatch file-system sources.

**Spec:** `docs/superpowers/specs/2026-11-20-leftless-v1.1-features-design.md`

## Global Constraints

- macOS 15.0+, Universal, sandbox off; bundle ID `com.leftless.app`; modules `Leftless` / `LeftlessCore`.
- Languages en (source), tr, de, fr, es, ja, pt-BR — every new key translated; plurals via catalog variations.
- Safety invariants unchanged: manifest saved before any move; nothing permanently deleted; protected/Apple paths never listed; possible/orphan items never pre-ticked; frozen confirmation plan; selection locked while working.
- **Commits must NOT contain any `Co-Authored-By` trailer or Claude attribution.** Commit author email for this repo is already configured (GitHub noreply) — don't change git config.
- After adding Swift files run `xcodegen generate` and commit the regenerated project; `xcodebuild -project Leftless.xcodeproj -scheme Leftless -destination 'platform=macOS' build` must succeed; `swift test` must pass.

## Review Focus

1. **Old history records** (no `operation` field) still decode as uninstall and restore — test (Task 1).
2. **Batch with one cancelled password prompt** — admin items of every app marked failed, non-admin items of all apps still trashed and recorded per app — test (Task 1).
3. **Orphan false positives** — helper IDs of an installed app (`com.vendor.app.helper`), vendor siblings, Group Containers with team prefix, Apple items are never listed — tests (Task 3).
4. **Trash watcher on a non-app or a duplicate event** — only new `.app` entries trigger once each; Leftless's own bundle ignored — test (Task 5).
5. **Reset never selects the app bundle, launch items or possible matches** — test (Task 6).

### Task 1: Core — history operation and batched Uninstaller

**Files:** Modify `Sources/LeftlessCore/History.swift`, `Sources/LeftlessCore/Uninstaller.swift`; Test `Tests/LeftlessCoreTests/UninstallerTests.swift`, `HistoryStoreTests.swift`.

**Interfaces (produces):**
- `public enum HistoryOperation: String, Codable, Sendable { case uninstall, reset, orphans }`; `HistoryRecord.operation: HistoryOperation` (init param default `.uninstall`; decoding defaults to `.uninstall` when the key is missing).
- `public struct UninstallJob: Sendable { scan: ScanResult; selected: [Leftover]; icon: Data?; operation: HistoryOperation }` (memberwise public init, `operation` default `.uninstall`).
- `Uninstaller.uninstall(batch: [UninstallJob]) throws -> [UninstallOutcome]` — one record per job; all records saved (pending) before any move (throw if any save fails, nothing moved); non-admin moves per job; admin items of all jobs retargeted together (unique names across jobs), records re-saved, then **one** `privileged.run`; states derived from the filesystem as today; receipts forgotten per the existing rules per job. `uninstall(_:selected:icon:)` delegates to a one-job batch (behaviour identical; existing tests unchanged).
- For `.orphans` jobs the record's `appName` is the scan's app name as given by the caller (Task 4 passes a localized "Orphaned leftovers" name and bundle ID `leftless.orphans`).

- [ ] Failing tests: `oldRecordWithoutOperationDecodesAsUninstall`; `batchWritesAllManifestsBeforeAnyMove`; `batchUsesSinglePrivilegedRunAcrossApps` (two jobs each with an admin item → `run` called once, both mv commands present); `batchAdminTargetsUniqueAcrossJobs` (same basename in two jobs → different trash targets); `batchCancelledMarksAdminItemsOfAllJobsFailed`; `singleUninstallStillBehavesAsBefore` (existing suite green).
- [ ] Implement; `swift test`; commit `feat(core): history operations and batched uninstall`.

### Task 3: Core — orphaned leftovers scanner

**Files:** Create `Sources/LeftlessCore/OrphanScanner.swift`, `Tests/LeftlessCoreTests/OrphanScannerTests.swift`; Modify `InstalledApps.swift` (add `allKnownBundleIDs(commands:) -> Set<String>` using the existing dirs at depth 2, `/System/Applications`, and `mdfind kMDItemContentType == 'com.apple.application-bundle'` via `CommandRunning`; Apple apps included).

**Interfaces:**
- `public struct OrphanGroup: Identifiable, Sendable { id: String /* identifier root */; displayName: String; items: [Leftover]; totalSize: Int64 }`.
- `public struct OrphanScanner { init(environment:, knownBundleIDs: Set<String>, restricted: Bool = false); func scan() -> OrphanScanResult }`, `OrphanScanResult { groups: [OrphanGroup] (sorted by totalSize desc); skippedLocations: [String] }`. All items `confidence: .probable`, kind from the location.
- Reverse-DNS test: ≥3 dot components after stripping a known extension (`.plist`, `.savedState`, `.binarycookies`) and, in Group Containers, a leading 10-char team ID component; first component in {com, org, net, io, co, app, dev, de, us, uk, fr, jp, me, tv, ai, info, ch, nl, se}.
- Owned if: protected/Apple; equals a known ID; is a dotted-prefix extension of a known ID (`com.v.app.helper`); or shares the vendor prefix (`com.v.`) with any known ID. LaunchAgents: orphan if reverse-DNS and owned-check fails **or** its Program/ProgramArguments[0] path does not exist and is not under /System or /usr.
- `displayName`: last component of the identifier root, title-cased (e.g. `com.vendor.soundwave` → "Soundwave").

- [ ] Failing tests (FakeSystem): `listsReverseDNSItemsOfUnknownApps`, `skipsInstalledAppAndItsHelpers`, `skipsVendorSiblings`, `teamPrefixedGroupContainerMatchedByID`, `skipsAppleAndProtected`, `skipsNonReverseDNSNames`, `launchAgentWithMissingProgramIsOrphan`, `restrictedSkipsContainers`, `groupsSortedBySize`, `allItemsUnticked`.
- [ ] Implement; commit `feat(core): orphaned leftovers scanner`.

### Task 5: Trash watch

**Files:** Create `Sources/LeftlessCore/TrashWatch.swift` (+ tests), `Sources/Leftless/Support/TrashWatcher.swift`, `Sources/Leftless/Support/LoginItem.swift`, `Sources/Leftless/Support/Notifications.swift`, `Sources/Leftless/Views/SettingsView.swift`; Modify `LeftlessApp.swift` (Settings scene, launch-at-login handling, notification response), `AppModel` (open a trashed app's scan), catalogs.

**Interfaces:**
- Core: `public enum TrashWatch { static func newApps(previous: Set<String>, current: [String], ignoring ownBundlePaths: Set<String>) -> [String] }` (names ending `.app`, not seen before, not ignored); tests `onlyNewAppsReported`, `nonAppsIgnored`, `sameAppNotReportedTwice`, `ownBundleIgnored`.
- `TrashWatcher` (@MainActor): `DispatchSource.makeFileSystemObjectSource` on `~/.Trash` (`.write`), debounce 1 s, diff via `TrashWatch.newApps`; for each new app: inspect bundle in Trash, scan with the existing scanner (installed list built in the task as in `select`), drop `.appBundle` leftovers; if any remain post a notification.
- Notifications: `UNUserNotificationCenter`, category with action "Clean Up"; userInfo carries the trashed app path; on response the app activates, opens the window, switches to Apps and shows that scan as a selected pseudo-app (`InstalledApp` built from the trashed bundle) — normal review/confirm flow.
- Settings: `@AppStorage("watchTrash")` default false; toggle disabled without Full Disk Access (explanatory text); enabling → request notification authorization, `SMAppService.mainApp.register()`, start watcher; disabling → `unregister()`, stop. On launch: if enabled, start watcher. Launched as login item (`NSAppleEventManager` `keyAELaunchedAsLogInItem` / `SMAppService` status) → no window (close it, `.accessory` policy) until the user opens Leftless or clicks a notification.
- [ ] Core tests → implement → manual smoke (with the setting on, move a fake app created in a temp dir to the Trash via Finder scripting is NOT allowed — instead unit tests + run the watcher against a temp directory in a test) → commit `feat: watch the Trash for deleted apps`.
